# Findings

Generated by `scripts/generate-findings.sh` on 2026-11-04, from the baseline commits of the nine demo repositories, with osv-scanner v2.7.0, npm audit (npm 11), pip-audit 2.10.1, govulncheck v1.9.0 (Go 1.27.3) and bandit 1.9.4.

- `sarif/*.osv-scanner.sarif`: one per repository
- `sarif/demo-session-router.govulncheck.sarif`: reachability-aware Go findings
- `sarif/demo-diagnostics.bandit.sarif`: the unsafe `yaml.load` call (B506)
- `jira-findings.csv`: one ticket per (repository, advisory). Aliases are de-duplicated. For Go, only advisories that call analysis marks as reachable are included. Severity is mapped from the advisory's CVSS score (≥9 Critical, ≥7 High, ≥4 Medium, otherwise Low). "Unscored" means the advisory has no CVSS score. `fixed_version` is the lowest fixed release above the installed version **for that advisory**. The version that clears every advisory for a package can be higher (see the playbook).

Scanner data changes as new advisories are published. Re-run the script before a demo if the dates are far apart.
